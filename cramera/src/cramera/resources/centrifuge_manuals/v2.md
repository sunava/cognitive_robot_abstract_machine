# CRAMERA laboratory centrifuge – Operating manual (simulation)

Document version: 2.0

This manual describes the simulated CRAMERA laboratory centrifuge with four
sample holders. It is not a manual for a real manufacturer's instrument.

## Operating rules

| Rule | Value |
| --- | --- |
| Minimum secured samples | 4 |

## Operation

1. Load the stopped rotor with the lid open.
2. Place samples in opposite holders and secure them.
3. Balance the mass of opposing samples.
4. Close the lid completely and start the centrifuge cycle.
5. Wait for the rotor to stop completely before opening the lid and unloading.

## Scope

The Operating rules table provides exactly one executable rule: the minimum
number of secured samples. This edition requires two balanced pairs. The physical
checks for lid position, balance, loose vessels and rotor speed also apply.
Observations come directly from MuJoCo; no visual recognition is claimed.
